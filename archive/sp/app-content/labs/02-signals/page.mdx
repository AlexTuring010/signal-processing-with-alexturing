<SourceDoc sources={{ pdf: 'Εργαστήριο/Εργαστήριο 2-Συνεχή και διακριτά σήματα.pdf' }} />

Στο [θεωρητικό κεφάλαιο για σήματα](/foundations/signals) είδαμε ότι υπάρχουν συνεχούς και διακριτού χρόνου σήματα, άρτια και περιττά, σήματα ενέργειας και σήματα ισχύος, κ.λπ. Εδώ φτιάχνουμε αυτά τα σήματα **πραγματικά** στο MATLAB.

<Callout type="key" title="Πώς αναπαριστούμε «συνεχή» σήματα στον υπολογιστή">
Ο υπολογιστής **δεν ξέρει συνεχή σήματα** — όλα τα νούμερα που χειρίζεται είναι διακριτά. Αυτό που κάνουμε είναι να **δειγματοληπτούμε** το συνεχές σήμα σε πολύ πυκνά χρονικά σημεία (π.χ. 1000 δείγματα/sec) και μετά να ενώνουμε τα δείγματα με γραμμές — έτσι φαίνεται συνεχές. Αν τα δείγματα είναι αρκετά πυκνά, η οπτική διαφορά εξαφανίζεται.
</Callout>

## Χρονικό διάνυσμα — το θεμέλιο

Κάθε σήμα ξεκινά με ένα διάνυσμα χρόνου. Δύο τρόποι:

```matlab
% Τρόπος 1 — colon notation: ορίζω βήμα Δt
t = 0:0.001:5;       % από 0 ως 5, βήμα 1 ms → 5001 σημεία

% Τρόπος 2 — linspace: ορίζω συνολικό αριθμό σημείων
t = linspace(0, 5, 5001);    % 5001 σημεία ομοιόμορφα στο [0, 5]
```

Και τα δύο δίνουν **το ίδιο** διάνυσμα στο παραπάνω παράδειγμα.

<Callout type="warning" title="Αρκετά πυκνό δείγμα;">
Ο γενικός κανόνας για το πόσο πυκνά να δειγματοληπτείς για **οπτικοποίηση**: τουλάχιστον 10× πιο πυκνά από τον γρηγορότερο κύκλο του σήματος. Π.χ. αν σχεδιάζεις `sin(2π·10t)` (συχνότητα 10 Hz, περίοδος 0.1 s), θέλεις βήμα ≤ 0.01 s. Με `0.001` (1 ms) είσαι πάντα ασφαλής για σήματα φωνής, μουσικής, και του δικού μας labs.
</Callout>

## Παράδειγμα 1 — Cosine με 3 παραμέτρους

Το σήμα `x(t) = 5·sin(8t)` στο διάστημα `0 ≤ t ≤ 5`:

```matlab
t = linspace(0, 5, 500);     % 500 δείγματα από 0 ως 5
x = 5 * sin(8 * t);
plot(t, x)
xlabel('t (s)'), ylabel('x(t)'), title('5 sin(8t)')
grid on
```

<Callout type="note" title="Παρατήρηση — στο sin το 8 είναι rad/s, όχι Hz">
Όταν γράφεις `sin(8*t)`, το `8` είναι η **γωνιακή συχνότητα** ω σε rad/s. Αν θες να ορίσεις σε **Hz**, γράφεις `sin(2*pi*f*t)` με `f` σε Hz. Στις διαφάνειες και στα παλιά θέματα δίνεται και με τους δύο τρόπους — πρόσεξε ποιον σου ζητάνε.
</Callout>

## Παράδειγμα 2 — Σήματα που ορίζονται κατά τμήματα

Η δουλειά εδώ είναι να σχεδιάσουμε:

$$
x(t) = \begin{cases} e^{-3t} - e^{-6t}, & t \geq 0 \\ 0, & t < 0 \end{cases}
$$

για `−2 ≤ t ≤ 3`.

Το **κόλπο** είναι να φτιάξεις μια λογική μάσκα `t >= 0` που είναι `1` όπου ισχύει η συνθήκη και `0` αλλού, και να πολλαπλασιάσεις:

```matlab
t = -2:0.01:3;
w = (t >= 0);                          % logical vector: 1 για t>=0, 0 αλλιώς
x = (exp(-3*t) - exp(-6*t)) .* w;      % το .* μηδενίζει για t<0
plot(t, x)
xlabel('t (s)'), ylabel('x(t)'), grid on
```

Αν θες περιορισμένο διάστημα `0 ≤ t ≤ 1`:

```matlab
w = (t >= 0) & (t <= 1);
x = (exp(-3*t) - exp(-6*t)) .* w;
plot(t, x)
```

<Callout type="key" title="Λογικοί τελεστές στο MATLAB — έλεγχοι σε vector">
- `&` — AND στοιχείο-προς-στοιχείο
- `|` — OR στοιχείο-προς-στοιχείο
- `~` — NOT (όχι `!`)
- `==`, `~=`, `<`, `>`, `<=`, `>=` — συγκρίσεις στοιχείο-προς-στοιχείο

Όλα αυτά επιστρέφουν διανύσματα από 0/1 (`logical` type) που μπορείς να **πολλαπλασιάσεις** με ένα σήμα για να «κόψεις» τμήματα.
</Callout>

## Βασικά σήματα — οι δομικοί λίθοι

### Βηματική συνάρτηση u(t)

Δύο τρόποι. **Inline** σαν λογική:

```matlab
u = double(t >= 0);    % double μετατρέπει το logical σε 0/1 αριθμητικά
plot(t, u)
```

ή σαν **function** σε δικό της `.m` αρχείο για επαναχρησιμοποίηση:

```matlab
% αρχείο: us.m
function u = us(t)
    u = 1 * (t >= 0);
end
```

```matlab
% στο command window:
t = -2:0.01:3;
u = us(t);
plot(t, u)
```

### Ράμπα r(t)

$$
r(t) = \begin{cases} t, & t \geq 0 \\ 0, & t < 0 \end{cases}
$$

```matlab
function r = ramp(t)
    r = t .* (t >= 0);    % t για t≥0, 0 αλλιώς
end
```

### Εκθετικά

```matlab
t = 0:0.1:10;
y1 = exp(2*t);       % αύξον εκθετικό
y2 = exp(-0.5*t);    % φθίνον εκθετικό
y3 = 0.8.^t;         % a^t με a<1 — επίσης φθίνον
y4 = 1.2.^t;         % a^t με a>1 — αύξον

subplot(2,2,1), plot(t, y1), title('e^{2t}')
subplot(2,2,2), plot(t, y2), title('e^{-0.5t}')
subplot(2,2,3), plot(t, y3), title('0.8^t')
subplot(2,2,4), plot(t, y4), title('1.2^t')
```

### Ορθογώνιος παλμός

Δύο τρόποι — με λογικές μάσκες ή με συνδυασμό step:

```matlab
% Τρόπος 1: λογική
t = -2:0.001:2;
rect = double(abs(t) <= 0.5);
plot(t, rect)

% Τρόπος 2: u(t) - u(t-T)  (μοναδιαία βήματα)
rect = us(t + 0.5) - us(t - 0.5);
plot(t, rect)
```

<Callout type="note" title="`us(t+0.5) - us(t-0.5)` — γιατί δουλεύει">
Το `us(t+0.5)` ανοίγει στο `t = -0.5`, το `us(t-0.5)` ανοίγει στο `t = +0.5`. Αν αφαιρέσεις, παίρνεις 1 στο διάστημα `[-0.5, 0.5]` και 0 παντού αλλού — δηλαδή ορθογώνιο πλάτους 1.
</Callout>

## Ημιτονοειδή σήματα συνεχούς χρόνου

Γενική μορφή:

$$
x(t) = A\cos(\Omega t + \theta) = A\cos(2\pi f t + \theta)
$$

όπου Ω σε **rad/s**, f σε **Hz**, και θ σε **rad**.

```matlab
A = 2;       % πλάτος
f = 5;       % συχνότητα σε Hz
theta = pi/4; % φάση σε rad

t = 0:0.001:1;     % 1 sec χρονικό διάστημα
x = A * cos(2*pi*f*t + theta);
plot(t, x)
xlabel('t (s)'), ylabel('x(t)'), grid on
title(sprintf('A=%g, f=%g Hz, \\theta=%g rad', A, f, theta))
```

## Διακριτά σήματα

Για ένα διακριτό σήμα `x[n] = cos(πn/3)`:

```matlab
n = 0:20;            % διακριτός χρόνος — ακέραιοι
x = cos(pi*n/3);
stem(n, x, 'filled')
xlabel('n'), ylabel('x[n]'), title('cos(\pin/3)')
grid on
```

<Callout type="warning" title="Στο διακριτό χρόνο η περιοδικότητα έχει «παγίδα»">
Για να είναι το `x[n] = cos(ω₀ n)` **περιοδικό** στο διακριτό χρόνο, χρειάζεται:

$$
\omega_0 N = 2\pi k, \quad k \in \mathbb{Z}
$$

δηλαδή `ω₀ / (2π) = k/N` πρέπει να είναι **ρητός αριθμός**. Π.χ. `cos(πn/3)` είναι περιοδικό με `N = 6`, αλλά `cos(n)` (ω₀ = 1) **δεν είναι** περιοδικό! Το θεωρητικό κεφάλαιο για [σήματα](/foundations/signals) έχει αναλυτική εξήγηση.
</Callout>

## Αριθμητικός υπολογισμός ενέργειας

Από το θεωρητικό κεφάλαιο: η ενέργεια ενός σήματος ορίζεται ως

$$
E = \int_{-\infty}^{\infty} |x(t)|^2 \, dt
$$

Στο MATLAB αυτό είναι **αριθμητική ολοκλήρωση**. Η εντολή `trapz` (τραπεζοειδής κανόνας):

```matlab
t = 0:0.001:5;
x = exp(-t);                  % ένα φθίνον εκθετικό
E = trapz(t, abs(x).^2);
fprintf('E ≈ %.4f\n', E);
% E ≈ 0.5000  (η αναλυτική απάντηση είναι 1/2)
```

<Callout type="key" title="Πότε χρησιμοποιείς `trapz`">
- Όταν έχεις σήμα **και** χρονικό διάνυσμα → `trapz(t, x)` (περιλαμβάνει τα Δt).
- Όταν έχεις μόνο τιμές χωρίς χρόνο → `trapz(x) * Δt` (πρέπει εσύ να πολλαπλασιάσεις με το βήμα).

Πάντα `abs(x).^2` και όχι `x.^2` — αν το σήμα είναι μιγαδικό, το πραγματικό `x.^2` δίνει λάθος αποτέλεσμα.
</Callout>

## Decomposition σε άρτιο & περιττό

Κάθε σήμα γράφεται ως άθροισμα ενός άρτιου και ενός περιττού:

$$
x(t) = x_e(t) + x_o(t), \quad x_e(t) = \tfrac{x(t)+x(-t)}{2}, \quad x_o(t) = \tfrac{x(t)-x(-t)}{2}
$$

Στο MATLAB το `x(-t)` δεν είναι «αυτονόητο» — το διάνυσμα `x` δεν ξέρει αρνητικό χρόνο. Το κόλπο είναι να **αναποδογυρίσεις** το διάνυσμα **και να φροντίσεις να είναι το `t` συμμετρικό γύρω από το 0**:

```matlab
t = -3:0.01:3;                % συμμετρικό!
x = exp(-t) .* (t >= 0);      % ένα one-sided σήμα
x_flipped = fliplr(x);        % αυτό είναι το x(-t) επειδή t→-t αντιστρέφει την σειρά

xe = (x + x_flipped) / 2;     % άρτιο μέρος
xo = (x - x_flipped) / 2;     % περιττό μέρος

subplot(3,1,1), plot(t, x),  title('x(t)')
subplot(3,1,2), plot(t, xe), title('x_e(t)')
subplot(3,1,3), plot(t, xo), title('x_o(t)')
```

Έλεγχος: αν προσθέσεις `xe + xo` πρέπει να πάρεις πίσω το `x`. Δοκίμασέ το.

## Ασκήσεις από παλιά θέματα εξετάσεων

<Example title="Άσκηση 1 (Ιούνιος 2019 — Ομάδα Z)">
**Δίνεται:**

$$
x(t) = (e^{-t} - e^{-2t}) u(t)
$$

Σχεδίασέ το με `plot` στο MATLAB. Στη συνέχεια σχεδίασε επίσης το `g(t) = x(2t - 1)`.

<Example title="Λύση" defaultOpen={true}>
```matlab
% Σήμα x(t)
t = -1:0.001:5;
x = (exp(-t) - exp(-2*t)) .* (t >= 0);

% Σήμα g(t) = x(2t - 1)
% Για να το πάρουμε, πάμε στο "ίδιο σχήμα" αλλά με αντικατάσταση
% του χρόνου: όπου t έβαζες πριν, τώρα βάζε (2t - 1)
g = (exp(-(2*t - 1)) - exp(-2*(2*t - 1))) .* ((2*t - 1) >= 0);

subplot(2,1,1), plot(t, x), title('x(t)'), grid on
subplot(2,1,2), plot(t, g), title('g(t) = x(2t - 1)'), grid on
```

**Σημείωση για τη δομή του g(t):** Ο μετασχηματισμός `t → 2t - 1` έχει δύο εφέ:
1. Ο πολλαπλασιαστής `2` **συμπιέζει** στον χρόνο κατά παράγοντα 2 (γρηγορότερο).
2. Το `-1` **μετατοπίζει**. Επειδή λύνεις `2t - 1 = 0 ⇒ t = 1/2`, η μετατόπιση είναι δεξιά κατά 1/2.

Για ολόκληρη τη θεωρία πίσω από τους μετασχηματισμούς, δες το reference page [Μετασχηματισμοί σήματος](/foundations/signal-transformations).
</Example>
</Example>

<Example title="Άσκηση 2 (Ιούνιος 2019 — Ομάδα E)">
**Δίνεται το ίδιο σήμα:** `x(t) = (e^{-t} - e^{-2t}) u(t)`

Σχεδίασε επίσης το `g(t) = x(-t + 2)`.

<Example title="Λύση" defaultOpen={true}>
```matlab
t = -3:0.001:5;
x = (exp(-t) - exp(-2*t)) .* (t >= 0);

% g(t) = x(-t + 2): αντικαθιστάς t → -t + 2
g = (exp(-(-t + 2)) - exp(-2*(-t + 2))) .* ((-t + 2) >= 0);

subplot(2,1,1), plot(t, x), title('x(t)'), grid on
subplot(2,1,2), plot(t, g), title('g(t) = x(-t + 2)'), grid on
```

**Σημείωση:** Ο πολλαπλασιαστής `-1` στο `-t + 2` είναι **κατοπτρισμός** (flip). Το `+2` είναι **μετατόπιση**. Συνολικά: παίρνεις το αρχικό σήμα, το αναποδογυρίζεις, και το μετακινείς ώστε αυτό που ήταν στο `t = 0` τώρα να είναι στο `t = 2`.
</Example>
</Example>

<Example title="Άσκηση 3 — δοκίμασε στο MATLAB">
Φτιάξε στο MATLAB μια **anonymous function** που υπολογίζει:

$$
f(x) = e^{-x^2 / 2}
$$

και σχεδίασε το γράφημα στο διάστημα `−4 ≤ x ≤ 4`.

<Example title="Λύση" defaultOpen={true}>
```matlab
f = @(x) exp(-x.^2 / 2);

x = -4:0.01:4;
plot(x, f(x))
xlabel('x'), ylabel('f(x)'), grid on
title('f(x) = e^{-x^2/2}')
```

**Παρατήρηση:** Χρειάζεται `.^` όχι `^` — η `x` εδώ είναι διάνυσμα, και θέλουμε **κάθε στοιχείο** στο τετράγωνο.

*(Παραλλαγή αυτής της ερώτησης πέφτει στις εξετάσεις 2019 και 2023.)*
</Example>

<Example title="Άσκηση 4 — Περιοδικό σήμα κατά τμήματα (style παλαιότερου lab exam)">
Σχεδίασε στο MATLAB το **περιοδικό** σήμα `x(t)` με περίοδο `T = 2.5 s` που ορίζεται μέσα σε μία περίοδο ως:

$$
x(t) = \begin{cases} t, & 0 \leq t < 1 \\ e^{-5t + 5}, & 1 \leq t < 2.5 \end{cases}
$$

για ολόκληρο το διάστημα `−2 ≤ t ≤ 12`.

<Example title="Λύση" defaultOpen={true}>
Η ιδέα: για κάθε χρονικό σημείο, βρίσκουμε «πού πέφτει μέσα σε μία περίοδο» χρησιμοποιώντας τη συνάρτηση **`mod`**. Μετά εφαρμόζουμε τον σωστό τύπο ανάλογα με το αν είμαστε στο ράμπα-τμήμα ή στο εκθετικό-τμήμα.

```matlab
T = 2.5;                       % περίοδος
t_total = -2:0.01:12;          % πλήρες χρονικό διάνυσμα
x_total = zeros(size(t_total));

for i = 1:length(t_total)
    t_index = mod(t_total(i), T);    % τιμή στο διάστημα [0, 2.5)
    if t_index <= 1
        x_total(i) = t_index;         % ράμπα
    else
        x_total(i) = exp(-5*t_index + 5);  % εκθετικό
    end
end

figure;
plot(t_total, x_total, 'm');
grid on;
title('x(t) — περιοδικό κατά τμήματα');
xlabel('t'), ylabel('x(t)');
```

<Callout type="key" title="Γιατί δουλεύει το `mod`">
`mod(t, 2.5)` επιστρέφει το **υπόλοιπο** της διαίρεσης `t / 2.5`. Πάντα στο διάστημα `[0, 2.5)`. Δηλαδή:
- `mod(0.5, 2.5) = 0.5` (μέσα στην 1η περίοδο)
- `mod(3.0, 2.5) = 0.5` (μέσα στη 2η περίοδο, αντιστοιχεί στην ίδια θέση όπως 0.5)
- `mod(-1.0, 2.5) = 1.5` (αρνητικά πάνε στην προηγούμενη περίοδο)

Αυτό είναι **ακριβώς** που χρειαζόμαστε για περιοδική επανάληψη.
</Callout>

**Vectorized εκδοχή** (πιο γρήγορη, χωρίς for-loop — δες [Lab 1](/labs/01-intro#flow-control)):

```matlab
T = 2.5;
t_total = -2:0.01:12;
t_idx = mod(t_total, T);
ramp_part = t_idx .* (t_idx <= 1);
exp_part  = exp(-5*t_idx + 5) .* (t_idx > 1);
x_total = ramp_part + exp_part;
plot(t_total, x_total, 'm'); grid on;
```

</Example>
</Example>

## Quick recap

- **Χρονικό διάνυσμα**: `t = 0:0.001:5` ή `linspace(0, 5, 5001)`.
- **Λογικές μάσκες**: `(t >= 0)`, `(t >= a) & (t <= b)`, πολλαπλασιάζονται με σήματα για να «κόψουν» τμήματα.
- **`plot` για συνεχή**, **`stem` για διακριτά**.
- **`trapz(t, abs(x).^2)`** για αριθμητική ενέργεια.
- **Μετασχηματισμοί σήματος** (`x(at + b)`): αντικαθιστάς το όρισμα στον τύπο.
