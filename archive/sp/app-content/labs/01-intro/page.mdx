## Τι είναι το MATLAB

**MAT**rix **LAB**oratory. Όλα είναι πίνακας. Ένας αριθμός είναι ένας 1×1 πίνακας. Ένα διάνυσμα είναι ένας 1×N ή N×1 πίνακας. Ένα σήμα στο χρόνο είναι ένα 1×N διάνυσμα. Αυτή η ομοιομορφία είναι που κάνει το MATLAB τόσο βολικό για επεξεργασία σήματος — αν ξέρεις άλγεβρα πινάκων, ξέρεις MATLAB.

Το περιβάλλον έχει τρία βασικά πάνελ:

- **Command Window** — εδώ γράφεις εντολές με το prompt `>>`. Όταν πατήσεις Enter, η εντολή εκτελείται και βλέπεις το αποτέλεσμα.
- **Workspace** — δείχνει όλες τις μεταβλητές που έχεις δηλώσει μέχρι στιγμής. Με διπλό κλικ ανοίγεις τον Variable Editor και βλέπεις τις τιμές σαν spreadsheet.
- **Current Directory / File Browser** — οι φάκελοι με τα `.m` αρχεία σου.

Δύο βασικές εντολές που θα τις χρησιμοποιείς συνέχεια:

```matlab
clear    % διαγράφει ΟΛΕΣ τις μεταβλητές από το workspace
clc      % καθαρίζει την οθόνη — οι μεταβλητές παραμένουν
```

## Πίνακες & διανύσματα

### Δηλώνεις έναν πίνακα

Με αγκύλες `[ ]`. **Κόμμα ή κενό** για στοιχεία της ίδιας γραμμής, **ερωτηματικό** για νέα γραμμή.

```matlab
>> A = [16 3; 5 10]
A =
    16     3
     5    10
```

Ένα διάνυσμα-γραμμή είναι απλώς ένας 1×N πίνακας:

```matlab
>> x = [1 2 5 1]
x =
     1     2     5     1
```

Ένας **τόνος** (`'`) είναι ο **ανάστροφος** (transpose):

```matlab
>> y = x'
y =
     1
     2
     5
     1
```

<Callout type="warning" title="Σύμβαση που πέφτει διαρκώς σε εξετάσεις">
Στις εξετάσεις του εργαστηρίου σε ρωτάνε συχνά «ποιες από τις παρακάτω εντολές δουλεύουν για `A` (2×3) και `B` (2×3);» — η απάντηση εξαρτάται από το αν χρειάζεσαι ανάστροφο. Π.χ. `A * B` **δεν δουλεύει** γιατί 2×3 · 2×3 δεν συμβατό, αλλά `A' * B` δουλεύει (3×2 · 2×3 → 3×3).
</Callout>

### Πίνακες με βήμα — η colon notation

```matlab
>> 1:5        % βήμα 1 (default)
ans =
     1     2     3     4     5

>> 0:0.25:1   % συγκεκριμένο βήμα
ans =
         0    0.2500    0.5000    0.7500    1.0000

>> -1:1:7     % start : step : end
ans =
    -1     0     1     2     3     4     5     6     7
```

Συναρτήσεις-εργαλεία για κατασκευή πινάκων:

```matlab
zeros(M, N)     % MxN πίνακας με μηδενικά
ones(M, N)      % MxN πίνακας με 1
rand(M, N)      % ομοιόμορφα κατανεμημένα στο (0,1)
randn(M, N)     % κανονικά κατανεμημένα, μ=0, σ=1
eye(N)          % NxN ταυτοτικός πίνακας
linspace(a,b,N) % N ισαπέχουσες τιμές από a μέχρι b (συμπεριλαμβανομένων)
```

<Callout type="key" title="`linspace` vs colon `:` — πότε ποιο">
Όταν σε νοιάζει ο **αριθμός** σημείων, χρησιμοποιείς `linspace(0, 5, 1000)`. Όταν σε νοιάζει το **βήμα**, χρησιμοποιείς `0:0.001:5`. Και τα δύο συναντιούνται στα labs.
</Callout>

### Indexing — η πιο συχνή ερώτηση στις εξετάσεις

**Το indexing στο MATLAB ξεκινάει από το 1**, όχι το 0. Αυτό αν είσαι από προγραμματισμό σε Python/C, χτυπάει συνέχεια.

```matlab
>> x = [10 20 30 40 50];
>> x(1)        % πρώτο στοιχείο
ans = 10
>> x(end)      % τελευταίο στοιχείο (special keyword)
ans = 50
>> x(2:4)      % στοιχεία από 2 έως 4 (inclusive!)
ans =
    20    30    40
```

Για 2D πίνακες με δύο indices `A(row, col)`:

```matlab
>> A = [1 2 3; 5 1 4; 3 2 -1];
>> A(2, 3)       % γραμμή 2, στήλη 3
ans = 4

>> A(3, :)       % ολόκληρη γραμμή 3
ans =
     3     2    -1

>> A(:, 2)       % ολόκληρη στήλη 2
ans =
     2
     1
     2
```

Το **`:`** σημαίνει «όλα τα στοιχεία στη διάσταση αυτή». Το διαβάζεις σαν «παίρνε τα όλα».

<Example title="Δοκίμασέ το — extract submatrix">
Δίνεται:
```matlab
A = [16  2  3 13;
      5 11 10  8;
      9  7  6 12;
      4 14 15  1];
```
Ποια από τα παρακάτω παράγουν το `B = [16 2; 5 11; 9 7; 4 14]`;

(A) `B = A(0:4, 0:2);`
(B) `B = A(1:4, 1:2);`
(Γ) `B = A(:, 0:2);`
(Δ) `B = A(:, 1:2);`

<Example title="Λύση" defaultOpen={true}>
**Σωστές: (B) και (Δ)**.

- (A), (Γ) είναι λάθος γιατί ξεκινάνε από το `0` — το MATLAB ξεκινάει από το `1`, δεν υπάρχει στοιχείο `A(0, ...)`.
- (B) `A(1:4, 1:2)` — γραμμές 1-4, στήλες 1-2 → οι 4 γραμμές, οι 2 πρώτες στήλες. ✓
- (Δ) `A(:, 1:2)` — όλες οι γραμμές, στήλες 1-2. Ίδιο αποτέλεσμα με το (B) γιατί ο πίνακας έχει 4 γραμμές. ✓

*(Παραλλαγή αυτής της ερώτησης πέφτει στις εξετάσεις 2020-21 και 2023.)*
</Example>
</Example>

### `[ ]` για concatenation, `( )` για indexing

Δύο **διαφορετικές** χρήσεις. Συχνά οι αρχάριοι τα μπερδεύουν.

```matlab
% Concatenation — βάζω πίνακες δίπλα-δίπλα ή πάνω-κάτω
a = [1 2];
b = [3 4];
c = [a b]            % οριζόντια → [1 2 3 4]
d = [a; b]           % κάθετα   → [1 2; 3 4]

% Indexing — διαλέγω στοιχεία από έναν πίνακα
x = [0 0 1 1 1 1];
y = x(2)             % το 2ο στοιχείο: 0
z = x(2:4)           % τα στοιχεία 2-4: [0 1 1]
```

## Πράξεις: η μεγαλύτερη παγίδα — `*` vs `.*`

Αυτό είναι **το κορυφαίο σημείο** που οι φοιτητές κάνουν λάθος. Είναι και κορυφαίο θέμα εξέτασης.

### Πράξεις πινάκων (αλγεβρικές)

```matlab
A + B          % πρόσθεση (στοιχείο-προς-στοιχείο, ίδιες διαστάσεις)
A - B          % αφαίρεση
A * B          % πολλαπλασιασμός ΠΙΝΑΚΩΝ — γραμμή · στήλη, χρειάζεται συμβατές διαστάσεις
A / B          % A * inv(B)
A \ B          % inv(A) * B  — λύσιμο γραμμικού συστήματος
A^2            % A * A — πολλαπλασιασμός πινάκων με τον εαυτό του
```

### Στοιχείο-προς-στοιχείο πράξεις (element-wise)

Βάζεις **τελεία `.`** μπροστά:

```matlab
A .* B         % στοιχείο-προς-στοιχείο πολλαπλασιασμός
A ./ B         % στοιχείο-προς-στοιχείο διαίρεση
A .^ 2         % κάθε στοιχείο στο τετράγωνο
```

<Callout type="warning" title="Πότε χρειάζεσαι την τελεία;">
**Όποτε δουλεύεις με σήματα.** Όταν έχεις δύο διανύσματα `t` και `x` και θες να φτιάξεις το `t .* sin(x)`, η τελεία **είναι υποχρεωτική** — αλλιώς το MATLAB σου λέει «error: inner matrix dimensions must agree». Η ίδια λογική για `t.^2`, `exp(-t).*cos(t)`, κ.λπ.
</Callout>

<Example title="Δοκίμασέ το — `*` vs `.*`">
Αν `T = [1 2 3 4 5 6 7]`, τι επιστρέφει το `T.^2` και τι το `T*T'`;

<Example title="Λύση" defaultOpen={true}>
- `T.^2 = [1 4 9 16 25 36 49]` — τετράγωνο **κάθε στοιχείου χωριστά**.
- `T*T' = 140` — αυτό είναι το **εσωτερικό γινόμενο**: `T` (1×7) · `T'` (7×1) = scalar (1×1) = `Σ T(i)^2 = 1+4+9+16+25+36+49 = 140`.

Το πρώτο είναι **διάνυσμα**, το δεύτερο είναι **αριθμός**. Εντελώς διαφορετικά πράγματα.
</Example>
</Example>

### Πράξεις με διανύσματα διαφορετικών διαστάσεων

Για πρόσθεση/αφαίρεση τα διανύσματα πρέπει να έχουν **ίδιο μέγεθος**. Αν ένα είναι γραμμή και το άλλο στήλη:

```matlab
row    = [1 2 3];      % 1×3
column = [4; 5; 6];    % 3×1
row + column           % WARNING: παλιότερα ήταν error, σε νέες εκδόσεις κάνει broadcasting
% Σωστή χρήση:
row + column'          % και τα δύο 1×3
row' + column          % και τα δύο 3×1
```

## Plotting — πώς εμφανίζεις σήματα

### Η εντολή `plot` για συνεχή σήματα

```matlab
x = -pi:0.01:pi;
y = sin(x);
plot(x, y)
grid on
title('sin(x)')
xlabel('x (rad)')
ylabel('y')
```

Δύο σήματα στο ίδιο γράφημα:

```matlab
y1 = sin(x);
y2 = cos(x);
plot(x, y1, x, y2)       % διαφορετικά χρώματα αυτόματα
legend('sin', 'cos')
```

Ή με `hold on` (συσσώρευση):

```matlab
plot(x, y1)
hold on
plot(x, y2)
legend('sin', 'cos')
hold off
```

### Η εντολή `stem` για διακριτά σήματα

```matlab
n = 0:20;
x = cos(pi*n/3);
stem(n, x)
title('cos(n\pi/3)')
xlabel('n')
```

`stem` ζωγραφίζει μια κάθετη γραμμή σε κάθε δείγμα, με κουκίδα στην κορυφή — αυτή είναι **η** οπτική σύμβαση για διακριτά σήματα.

<Callout type="key" title="Όταν δεν είσαι σίγουρος αν είναι συνεχές ή διακριτό">
Στο MATLAB **όλα** είναι στην πραγματικότητα διακριτά (αριθμοί σε vector). Η διαφορά είναι μόνο πώς το **εμφανίζεις**:
- `plot`: ενώνει τα σημεία με γραμμές → φαίνεται συνεχές.
- `stem`: εμφανίζει κάθε δείγμα σαν stem → φαίνεται διακριτό.

Αν το βήμα δειγματοληψίας είναι πολύ πυκνό (`0.01` ή και πιο μικρό), το `plot` δίνει εικόνα συνεχούς σήματος. Αν είναι χοντρό (π.χ. βήμα `1`), χρησιμοποιείς `stem`.
</Callout>

### Πολλαπλά γραφήματα — `subplot`

Για να βάλεις δύο plots στο ίδιο figure window, ένα κάτω από το άλλο:

```matlab
x = -pi:0.01:pi;
subplot(2, 1, 1)       % 2 γραμμές × 1 στήλη, τρέχουσα θέση = 1
plot(x, sin(x))
title('sin')
subplot(2, 1, 2)
plot(x, cos(x))
title('cos')
```

Το `subplot(2,1,1)` διαβάζεται «2 γραμμές, 1 στήλη, διάλεξε την 1η θέση». Παλιότερη γραφή `subplot(211)` σημαίνει το ίδιο πράγμα.

## Scripts vs Functions — **κορυφαία ερώτηση εξέτασης**

Στο MATLAB γράφεις κώδικα σε αρχεία `.m`. Υπάρχουν **δύο είδη** τέτοιων αρχείων.

### Scripts

Μια λίστα εντολών. Δουλεύει σαν να τις πληκτρολόγησες μία-μία στο command window. **Έχει πρόσβαση** στο workspace και **αλλάζει** τις μεταβλητές του.

```matlab
% αρχείο: myScript.m
x = 1:10;
y = x.^2;
plot(x, y)
```

Στο command window:

```matlab
>> myScript      % τρέχει όλες τις εντολές, το x και y μένουν στο workspace
```

### Functions

Έχουν **inputs** και **outputs**, και **δικό τους τοπικό workspace** — οι μεταβλητές μέσα στη function δεν επηρεάζουν το έξω.

```matlab
% αρχείο: randint.m  (πρέπει το αρχείο να έχει το ίδιο όνομα με τη function!)
function a = randint(m, n)
% This function generates an mxn matrix of random integers between 0 and 9
    a = floor(10 * rand(m, n));
end
```

Καλείται:

```matlab
>> A = randint(5, 3);    % φτιάχνει 5×3 πίνακα με τυχαίους ακέραιους 0-9
```

Όταν θέλεις **πολλαπλά outputs**, βάζεις τα ονόματα σε αγκύλες:

```matlab
function [a, b, c] = myFunc(x, y)
    a = x + y;
    b = x - y;
    c = x * y;
end
```

και την καλείς:

```matlab
>> [s, d, p] = myFunc(3, 4);   % s=7, d=-1, p=12
```

<Callout type="key" title="Σύγκριση scripts vs functions (παλιό θέμα εξέτασης)">
**Τι ισχύει για functions και scripts;**

✓ **Τα scripts δεν έχουν μεταβλητές εισόδου ούτε εξόδου** — απλώς εκτελούν εντολές.
✓ **Τα scripts χρησιμοποιούν το workspace του command window** — μοιράζονται μεταβλητές.
✓ **Μπορούμε να καλέσουμε μια function μέσα σε μια άλλη function**, αλλά **δεν** μπορούμε να καλέσουμε ένα script μέσα σε μια function (στις παλιότερες εκδόσεις — στις νέες υπάρχουν local functions).
✗ Δεν είναι αλήθεια ότι «οι functions πρέπει να έχουν μεταβλητές εισόδου ΚΑΙ εξόδου» — μπορούν να έχουν 0 inputs ή 0 outputs.
</Callout>

### Anonymous functions — μικρά function χωρίς αρχείο

Όταν θες μια **απλή function** χωρίς να φτιάξεις ξεχωριστό αρχείο, υπάρχει συντομογραφία:

```matlab
>> square = @(x) x.^2;
>> square(5)
ans = 25

>> f = @(x) sin(4*x) - log(x);
>> f(0.5)
ans = -0.2716   % περίπου
```

Το `@(x)` σημαίνει «δημιουργώ μια function με όρισμα `x`». Μπορεί να έχει πολλαπλά ορίσματα: `f = @(x, y) x.^2 + y.^2`.

<Callout type="warning" title="Σωστή vs λάθος σύνταξη — εξεταστική παγίδα">
**Σωστό:** `f = @(x) sin(4*x) - log(x);`

**Λάθος:** `f(x) = @(x) sin(4*x) - log(x);` ⟵ ΟΧΙ. Στα anonymous γράφεις το όνομα της variable, όχι την «κλήση».

**Λάθος:** `f = @ (sin(4*x) - log(x));` ⟵ ΟΧΙ. Χρειάζεται οπωσδήποτε `@(x)` με την λίστα παραμέτρων.
</Callout>

Τα anonymous functions είναι **απίστευτα χρήσιμα** στο [Lab 3](/labs/03-systems) όπου ορίζουμε «συστήματα» σαν συναρτήσεις.

## Flow control — `for`, `if`, `while`

### `for` loop

```matlab
for k = 1:10
    x(k) = cos(k);
end
```

αλλά **ισοδύναμα** (και πολύ πιο γρήγορα) με vectorization:

```matlab
k = 1:10;
x = cos(k);
```

### `if` statement

```matlab
if a <= 2
    b = 1;
elseif a >= 4
    b = 2;
else
    b = 3;
end
```

Τελεστές σύγκρισης: `==`, `~=` (όχι ίσο), `<`, `>`, `<=`, `>=`. **Όχι `=`** — το `=` είναι ανάθεση τιμής.

### `while` loop

```matlab
n = 0;
while n < 10
    n = n + 1;
end
```

<Callout type="key" title="Vectorization > loops">
Για κάθε φορά που θες να βάλεις ένα `for` loop, ρώτα τον εαυτό σου: **μπορώ να το κάνω χωρίς loop με πράξεις πινάκων;**

Παράδειγμα — μέτρα πόσα στοιχεία του `x` είναι θετικά:

```matlab
% Με loop (αργό)
count = 0;
for n = 1:length(x)
    if x(n) > 0
        count = count + 1;
    end
end

% Χωρίς loop (10× πιο γρήγορο και πιο σύντομο)
count = length(find(x > 0));
% ή ακόμα πιο σύντομο
count = sum(x > 0);    % το `x > 0` δίνει vector από 0/1, sum τα αθροίζει
```

Στις εξετάσεις σου ζητάνε **«ποιος από τους παρακάτω τρόπους είναι ισοδύναμος με τον κώδικα χωρίς for-loop;»** — η σωστή απάντηση είναι σχεδόν πάντα ένας vectorized one-liner.
</Callout>

<Example title="Δοκίμασέ το — αντικατάσταση for-loop">
Δίνονται:
```matlab
A = [πίνακας 10×10];
x = [διάνυσμα 10×1];
v = zeros(10, 1);
for i = 1:10
    for j = 1:10
        v(i) = v(i) + A(i,j) * x(j);
    end
end
```
Ποια από τα παρακάτω είναι ισοδύναμα με τον παραπάνω κώδικα;

(A) `v = A * x;`
(B) `v = x' * A;`
(Γ) `v = A .* x;`
(Δ) `v = sum(A * x);`

<Example title="Λύση" defaultOpen={true}>
**Σωστό: (A) μόνο.**

Ο διπλά εμφωλιασμένος `for` υπολογίζει `v(i) = Σ_j A(i,j) * x(j)` — αυτό είναι ακριβώς **ο ορισμός του πολλαπλασιασμού πίνακα-διάνυσμα** `v = A*x`.

- (B) `x' * A` δίνει διάνυσμα-γραμμή 1×10, όχι 10×1. Λάθος διάσταση.
- (Γ) `A .* x` — προσπάθεια στοιχείο-προς-στοιχείο μεταξύ 10×10 και 10×1. Δεν είναι αυτό που υπολογίζει ο loop.
- (Δ) `sum(A * x)` δίνει έναν αριθμό (άθροισμα όλων των στοιχείων του `A*x`), όχι διάνυσμα.
