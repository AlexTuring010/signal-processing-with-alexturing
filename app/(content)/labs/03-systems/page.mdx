Στο [θεωρητικό κεφάλαιο για συστήματα](/foundations/systems) είδαμε τι σημαίνει ένα σύστημα να είναι **γραμμικό** (ισχύει η αρχή της υπέρθεσης) και **χρονικά αμετάβλητο** (μια χρονική ολίσθηση στην είσοδο δίνει την ίδια ολίσθηση στην έξοδο). Εδώ θα δούμε πώς **επαληθεύουμε αριθμητικά** αυτές τις ιδιότητες στο MATLAB.

<Callout type="key" title="Γιατί υπολογιστικός έλεγχος;">
Στο χαρτί κάνεις αλγεβρικό έλεγχο: αντικαθιστάς `αx₁ + βx₂` στο σύστημα και βλέπεις αν προκύπτει `αy₁ + βy₂`. Στο MATLAB κάνεις **εμπειρικό** έλεγχο: τρέχεις τα δύο σήματα από το σύστημα ξεχωριστά + το άθροισμα μέσα στο σύστημα, και βλέπεις αν τα δύο γραφήματα συμπίπτουν.

Ο εμπειρικός έλεγχος **δεν αποδεικνύει** γραμμικότητα — αν δεις διαφορά, ξέρεις σίγουρα ότι **δεν** είναι γραμμικό. Αν δεις ταύτιση, είναι **υπόνοια** ότι είναι γραμμικό (αλλά μπορεί απλώς να έτυχε για τα συγκεκριμένα σήματα που δοκίμασες).
</Callout>

## Anonymous functions ως «συστήματα»

Η πιο φυσική γέφυρα μεταξύ θεωρίας και MATLAB: ορίζεις ένα σύστημα ως **anonymous function** που παίρνει σήμα εισόδου `x` και επιστρέφει σήμα εξόδου `y`.

```matlab
sys_a = @(x) 5 * x;             % y(t) = 5 x(t)
sys_b = @(x) 5 * x + 3;         % y(t) = 5 x(t) + 3
sys_c = @(x) 3 * x.^2;          % y(t) = 3 [x(t)]^2
sys_d = @(x) cos(x);            % y(t) = cos(x(t))
```

<Callout type="warning" title="Το `.^` αντί για `^` είναι κρίσιμο">
Στο `sys_c = @(x) 3 * x.^2;` η τελεία είναι **υποχρεωτική** γιατί το `x` εδώ θα είναι **διάνυσμα**. Χωρίς τελεία, το MATLAB θα προσπαθήσει `x * x` (πολλαπλασιασμό πινάκων), που για ένα διάνυσμα 1×N δίνει error.
</Callout>

## Έλεγχος γραμμικότητας

Παίρνουμε δύο σήματα `x1`, `x2` και δύο σταθερές `α1`, `α2`. Συγκρίνουμε:

- **Αναμενόμενη έξοδος** αν είναι γραμμικό: `α1 * sys(x1) + α2 * sys(x2)`
- **Πραγματική έξοδος**: `sys(α1*x1 + α2*x2)`

Αν είναι ίσα → υπόνοια γραμμικότητας. Αν διαφέρουν → **σίγουρα όχι** γραμμικό.

```matlab
t = 0:0.01:4;
x1 = cos(2*pi*5*t);
x2 = exp(-0.5*t);
alpha1 = 2;
alpha2 = 1.25;
x = alpha1*x1 + alpha2*x2;

% Ορισμός όλων των συστημάτων
sys_a = @(x) 5*x;
sys_b = @(x) 5*x + 3;
sys_c = @(x) 3*x.^2;
sys_d = @(x) cos(x);

% Έλεγχος sys_a
y1 = sys_a(x1);
y2 = sys_a(x2);
y_exp = alpha1*y1 + alpha2*y2;     % αναμενόμενο αν γραμμικό
y_act = sys_a(x);                  % πραγματικό

subplot(2,1,1);
plot(t, y_exp);
title('y_{exp} = \alpha_1 y_1 + \alpha_2 y_2')
xlabel('t (s)'), ylabel('Amplitude')

subplot(2,1,2);
plot(t, y_act);
title('y_{act} = Sys_a\{\alpha_1 x_1 + \alpha_2 x_2\}')
xlabel('t (s)'), ylabel('Amplitude')
```

Αν τα δύο γραφήματα είναι **ταυτόσημα**, το σύστημα φαίνεται γραμμικό. Για το `sys_a` αυτό είναι όντως αληθές (γραμμικό). Για το `sys_b` θα δεις σταθερή διαφορά (επειδή το `+3` σπάει την υπέρθεση). Για το `sys_c` και `sys_d` θα δεις εντελώς διαφορετικά σχήματα.

<Example title="Άσκηση 1 — γραμμικότητα">
Δοκίμασε στο MATLAB όλα τα τέσσερα συστήματα `sys_a, sys_b, sys_c, sys_d` με τα παραπάνω `x1, x2`. Ποια συμπίπτουν με τη γραμμική πρόβλεψη;

<Example title="Λύση" defaultOpen={true}>
- **`sys_a = 5x`** — Γραμμικό. ✓
- **`sys_b = 5x + 3`** — **Όχι** γραμμικό. Στην `y_act` έχει `+3` μία φορά, στην `y_exp` έχει `α1·3 + α2·3 = 3(α1+α2) = 3·3.25 = 9.75`. Διαφορά.
- **`sys_c = 3x²`** — **Όχι** γραμμικό. Το τετράγωνο σπάει την αρχή της υπέρθεσης: `(x1+x2)² ≠ x1² + x2²`.
- **`sys_d = cos(x)`** — **Όχι** γραμμικό. `cos(x1+x2) ≠ cos(x1) + cos(x2)`.

**Γενικά:** Συστήματα της μορφής `y = a·x` ή `y = a(t)·x + b(t)·x'` (γραμμικός συνδυασμός παραγώγων/ολοκληρωμάτων της `x` με συντελεστές που εξαρτώνται μόνο από το `t`) είναι γραμμικά. Οτιδήποτε προσθετική σταθερά, δύναμη του `x`, μη γραμμική συνάρτηση όπως `cos(x)`, `exp(x)`, `|x|` το χαλάει.
</Example>
</Example>

## Έλεγχος χρονικής αμεταβλητότητας

Ένα σύστημα είναι **χρονικά αμετάβλητο** αν:

$$
\text{Sys}\{x(t - \tau)\} = y(t - \tau)
$$

Δηλαδή: ολισθαίνω την είσοδο, παίρνω την ίδια έξοδο ολισθημένη.

Στο MATLAB συγκρίνουμε δύο σήματα:

1. **`sys(x(t))` μετά ολίσθηση**: παίρνω την έξοδο για το αρχικό σήμα, και την ολισθαίνω κατά `τ`.
2. **`sys(x(t - τ))`**: τρέχω το **ήδη ολισθημένο** σήμα μέσα από το σύστημα.

Αν τα δύο σήματα είναι **ίδια** → χρονικά αμετάβλητο. Αν **διαφέρουν** → όχι χρονικά αμετάβλητο.

### Παράδειγμα — με anonymous functions

Δίνονται 3 συστήματα:

- `y₁(t) = 3 cos(x(t))` — χρονικά αμετάβλητο
- `y₂(t) = 3 cos(t) · x(t)` — **όχι** χρονικά αμετάβλητο (η `cos(t)` εξαρτάται **απευθείας** από `t`)

Δοκιμή με σήμα `x(t) = e^{-5(t-1)} u(t)` και ολίσθηση `τ = 2`:

```matlab
t = -1:0.01:6;
u = @(t) (t >= 0);
x = @(t) exp(-5*(t - 1)) .* u(t);

y1 = @(t) 3*cos(x(t));            % χρονικά αμετάβλητο
y2 = @(t) 3*cos(t) .* x(t);       % ΟΧΙ χρονικά αμετάβλητο

% --- Σύστημα y1 ---
figure;
subplot(3,1,1);
plot(t, y1(t));
title('y(t) = 3 cos(x(t))'), xlabel('t'), ylabel('y(t)'), grid on

subplot(3,1,2);
plot(t, y1(t - 2), 'm');           % παίρνω την έξοδο και την ολισθαίνω
title('y(t - 2)'), xlabel('t'), ylabel('y(t-2)'), grid on

subplot(3,1,3);
plot(t, 3*cos(x(t - 2)), 'g');     % τρέχω την ολισθημένη είσοδο μέσα στο σύστημα
title('Sys\{x(t - 2)\}'), xlabel('t'), ylabel('y(t)'), grid on
```

**Αποτέλεσμα:** Το δεύτερο και τρίτο subplot είναι ταυτόσημα → επιβεβαιώνεται ότι το `y1` είναι χρονικά αμετάβλητο.

```matlab
% --- Σύστημα y2 ---
figure;
subplot(3,1,1);
plot(t, y2(t));
title('y(t) = 3 cos(t) x(t)'), grid on

subplot(3,1,2);
plot(t, y2(t - 2), 'r');           % έξοδος ολισθημένη
title('y(t - 2)'), grid on

subplot(3,1,3);
plot(t, 3*cos(t) .* x(t - 2), 'y');  % τρέχω ολισθημένη είσοδο μέσα στο σύστημα
title('Sys\{x(t - 2)\}'), grid on
```

**Αποτέλεσμα:** Το δεύτερο και τρίτο subplot είναι **διαφορετικά** → επιβεβαιώνεται ότι το `y2` δεν είναι χρονικά αμετάβλητο. Ο λόγος: η `cos(t)` στο `y2` εξαρτάται **από τον "απόλυτο" χρόνο**, όχι μόνο από την είσοδο — οπότε αν αλλάξεις πότε φτάνει η είσοδος, το σύστημα την «πολλαπλασιάζει» με διαφορετική στιγμιαία τιμή της `cos(t)`.

<Callout type="key" title="Το κανόνας του «t στο σύστημα»">
Όταν δεις στον τύπο του συστήματος ένα `t` (ή `n`) **εκτός** της εισόδου `x(...)` — π.χ. ένας πολλαπλασιαστής `t`, ένας `cos(t)`, ένας `t²` — αυτό είναι **κόκκινη σημαία** ότι το σύστημα δεν είναι χρονικά αμετάβλητο.

Αν όλο το `t` εμφανίζεται **μόνο μέσα στο όρισμα** της `x` (π.χ. `x(t)`, `x(t-3)`, `x(2t)`, `dx/dt`), τότε υπάρχει πιθανότητα να είναι χρονικά αμετάβλητο.
</Callout>

<Example title="Άσκηση 2 — δοκίμασε τα παρακάτω συστήματα">
Για καθένα από τα παρακάτω, αποφάσισε **πρώτα στο χαρτί** αν είναι ΧΑ και μετά **επαλήθευσε στο MATLAB**:

1. `y(t) = 5 x(t)`
2. `y(t) = 3 cos(x(t))`
3. `y(t) = x(2t)` (χρονική κλιμάκωση)
4. `y(t) = t · x(t)`

<Example title="Λύση" defaultOpen={true}>
1. **`y = 5x` — ΧΑ ✓**. Καμία `t` εμφάνιση εκτός της `x`. Δοκιμή: `5·x(t-τ)` = ολίσθηση της `5·x(t)`. Σωστό.

2. **`y = 3 cos(x)` — ΧΑ ✓**. Η `t` εμφανίζεται μόνο μέσα στην `x`. Δοκιμή: `3 cos(x(t-τ))` = ολίσθηση της `3 cos(x(t))`. Σωστό.

3. **`y = x(2t)` — ΟΧΙ ΧΑ ✗**. Παγίδα! Παρόλο που η `t` εμφανίζεται μόνο μέσα στην `x`, ο πολλαπλασιαστής `2` σπάει την αμεταβλητότητα. Δοκιμή:
   - `y(t-τ) = x(2(t-τ)) = x(2t - 2τ)`
   - `Sys{x(t-τ)} = x(2t - τ)`
   - Διαφέρουν για `τ ≠ 0`. Είναι **χρονική κλιμάκωση**, ξεχωριστή κατηγορία.

4. **`y = t · x(t)` — ΟΧΙ ΧΑ ✗**. Το `t` εμφανίζεται έξω από την `x`. Σπάει αμέσως.

```matlab
% Επαληθεύεις στο MATLAB όλα ως εξής:
t = -1:0.01:6;
u = @(t) (t >= 0);
x = @(t) exp(-5*(t - 1)) .* u(t);

% Σύστημα 1: y = 5x
sys1 = @(x_input) 5 * x_input;
% τότε `sys1(x(t-2))` vs `sys1(x(t))` ολισθημένο κατά 2 → πανομοιότυπα

% Σύστημα 3: y = x(2t) — δυσκολότερο να γραφτεί σαν anonymous function γιατί
% το "σύστημα" χρειάζεται την μαθηματική μορφή του x. Καλύτερα να γράψεις:
sys3 = @(t_arg) x(2 * t_arg);     % παίρνει χρόνο, επιστρέφει σήμα
plot(t, sys3(t)); hold on
plot(t, sys3(t - 2), 'r');           % τρέχει ολισθημένο μέσα στο σύστημα
plot(t, x(2*(t - 2)), 'g--');        % ίδιο πράγμα γραμμένο διαφορετικά
hold off
```
</Example>
</Example>

## Convolution στο MATLAB

Από τη θεωρία ξέρουμε ότι η έξοδος ενός LTI συστήματος δίνεται από:

$$
y(t) = (x * h)(t) = \int_{-\infty}^{\infty} x(\tau)\,h(t - \tau)\,d\tau
$$

Στο MATLAB υπάρχει η εντολή **`conv`**:

```matlab
y = conv(x, h);
```

που υλοποιεί τη διακριτή συνέλιξη. Αν τα `x` και `h` έχουν μήκη `N` και `M`, η έξοδος έχει μήκος `N + M - 1`.

### Παράδειγμα — convolution δύο ορθογώνιων παλμών

Από τη θεωρία, η συνέλιξη δύο ίδιων ορθογώνιων παλμών δίνει τριγωνικό παλμό. Ελέγχουμε αριθμητικά:

```matlab
t = -2:0.01:2;
x = double(abs(t) <= 0.5);     % ορθογώνιο πλάτους 1, διάρκειας 1
h = x;                          % ίδιο σήμα ως κρουστική απόκριση

y = conv(x, h) * 0.01;         % πολλαπλασιάζουμε με Δt (= 0.01) για σωστή κλίμακα
t_y = (2*t(1)) : 0.01 : (2*t(end));   % νέος άξονας χρόνου, μήκος N+M-1

subplot(3,1,1), plot(t, x), title('x(t) — ορθογώνιο'), grid on
subplot(3,1,2), plot(t, h), title('h(t) — ίδιο'), grid on
subplot(3,1,3), plot(t_y, y), title('y = x * h — τρίγωνο'), grid on
```

<Callout type="warning" title="Το πολλαπλασιαστικό `Δt`">
Όταν χρησιμοποιείς `conv` για **συνεχή** σήματα που έχεις δειγματοληπτήσει, **πρέπει** να πολλαπλασιάσεις με το βήμα δειγματοληψίας `Δt`. Αυτό συμβαίνει επειδή το `conv` αθροίζει (δεν ολοκληρώνει), και χωρίς `Δt` το αποτέλεσμα είναι κλιμακωμένο κατά `1/Δt`.

Για **διακριτά** σήματα (όπου δεν υπάρχει «έννοια χρόνου»), δεν χρειάζεται πολλαπλασιασμός — η `conv` δίνει το σωστό αποτέλεσμα.
</Callout>

### Cascade & parallel σύνθεση

Από τη θεωρία:
- Cascade (αλυσίδα): `h_eq = h1 * h2`
- Parallel (παράλληλο): `h_eq = h1 + h2`

Στο MATLAB:

```matlab
% Cascade
h_cascade = conv(h1, h2) * dt;

% Parallel (πρέπει να έχουν ίδιο μήκος)
h_parallel = h1 + h2;
```

## Quick recap

- **Ορίζεις συστήματα ως anonymous functions** `sys = @(x) ...`. Το `.^`, `.*`, `./` είναι **υποχρεωτικά**.
- **Γραμμικότητα**: σύγκρινε `sys(α1*x1 + α2*x2)` με `α1*sys(x1) + α2*sys(x2)`. Διαφορά → όχι γραμμικό.
- **Χρονική αμεταβλητότητα**: σύγκρινε `y(t-τ)` με `sys(x(t-τ))`. Διαφορά → όχι ΧΑ.
- **Κανόνας του παρατηρητή**: εμφάνιση `t` εκτός της `x(...)` → πιθανότατα όχι ΧΑ.
- **Convolution**: `conv(x, h)`, πολλαπλασιασμός με `Δt` για συνεχή σήματα.
