## ReorderDrill

<ReorderDrill
  id="showcase-am-solve-order"

    </p>
  }
  steps={[
    <>Γράφεις τον ορισμό <InlineMath>{'\\mu = A_m / A_c'}</InlineMath> και υπολογίζεις την τιμή του.</>,

    <>Υπολογίζεις την ισχύ του carrier: <InlineMath>{'P_c = A_c^2 / 2'}</InlineMath>.</>,
    <>Εφαρμόζεις <InlineMath>{'P_{AM} = P_c\\,(1 + \\mu^2/2)'}</InlineMath> και δίνεις την τελική τιμή.</>,
